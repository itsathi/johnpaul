This project includes a premium cinematic entrance experience for John Paul's personal website.

## Key Files

- **`app/entrance/page.tsx`** - The cinematic entrance with 5 doors
- **`app/page.tsx`** - Main website with strategic 10-step narrative funnel

## Installation

```bash
npm run dev
```

## Features

### Cinematic Entrance

The entrance features:

1. **Five Distinct Pathways**: 
   - JOHN PAUL LIVE (stage performances)
   - JOHN PAUL SHOP (merchandise)
   - JOHN PAUL SESSIONS (studio recordings)
   - JOHN PAUL LESSONS (guitar instruction)
   - SCROLL TO EXPLORE JOHN PAUL (complete ecosystem)

2. **Premium Visuals**:
   - Deep black/dark backgrounds
   - Film grain overlay
   - Editorial typography
   - Sophisticated European aesthetic

3. **Advanced Interactions**:
   - Mouse-tracking flashlight reveal effect
   - Custom cinematic cursor
   - Smooth hover animations
   - Cinematic transitions

4. **Performance Optimized**:
   - GPU-accelerated transforms
   - `prefers-reduced-motion` support
   - 60fps target
   - Lazy loading

## Notes

- The entrance is only shown once per session using localStorage
- After first visit, users are redirected directly to the main site
- Mobile devices use touch-based interactions instead of mouse
- All transitions are cinema-inspired with smooth interpolation
