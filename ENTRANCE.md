This project now includes a cinematic entrance experience for John Paul's personal website.

## What's New

### 1. **Cinematic Entrance Page** (`app/entrance/page.tsx`)

A full-screen immersive dark experience that features:

- **Five distinct pathways** (styled as "doors" into John's world):
  - **JOHN PAUL LIVE** - Stage performance imagery
  - **JOHN PAUL SHOP** - Merchandise and vinyl
  - **JOHN PAUL SESSIONS** - Studio recording environment  
  - **JOHN PAUL LESSONS** - Guitar instruction visuals
  - **SCROLL TO EXPLORE JOHN PAUL** - Complete artistic ecosystem entry

- **Mouse-tracking flashlight reveal effect** - Dark backdrop images reveal as you move your mouse

- **Custom cinematic cursor** - Refined cursor with smooth spring physics

- **Film grain overlay** - Premium analog aesthetic texture

- **Smooth cinematic transitions** - Fluid hover states and chapter transitions

### 2. **Visual Design**

- Deep black/near-black background with sophisticated typography
- Editorial serif + modern sans-serif typography hierarchy
- Large, spacious typography with excellent negative space
- Subtle analog/film aesthetic
- Premium contemporary music artist website feel
- Sophisticated European editorial website inspiration

### 3. **Interaction Design**

- Hover effects with smooth typography expansion and image reveals
- Custom cursor that changes and shows labels on interaction
- Scroll-triggered transition into the main homepage
- Cinematic chapter transitions when selecting a pathway
- Responsive design for mobile, tablet, and desktop

### 4. **Technical Implementation**

- GPU-accelerated transforms and animations
- `requestAnimationFrame` for smooth 60fps performance
- `prefers-reduced-motion` respect
- `pointer: fine` check for custom cursor availability
- Smooth interpolation and easing functions
- Light image loading and performance optimization

## How to Use

1. **First Visit**: Visit the website - you'll be greeted by the cinematic entrance
2. **Explore**: Hover over any of the five doors to see subtle imagery and transitions
3. **Enter**: Select a door or scroll down to enter the main website
4. **Navigate**: Use the main navigation to explore John's complete artistic ecosystem

## Key Features

- The entrance is **only shown once per session** - on subsequent visits, you go directly to the main site
- The experience feels like **entering an artist's world**, not a conventional website
- All transitions and interactions are **premium and intentional**
- The design communicates John's identity as a **performing artist, session musician, educator, and creator**

The cinematic entrance creates the perfect first impression, immediately communicating that this is "not just a musician's website" but a complete artistic ecosystem worth exploring.
